# Halloween Mad Libs

Halloween Mad Libs is an interactive Rust program that asks the user for different words and places them into a funny Halloween story.

## Instructions for Build and Use

Steps to build and run the software:

1. Install Rust from [rustup.rs](https://rustup.rs/).
2. Save the program as `main.rs`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   ```bash
   rustc main.rs
   ```

5. Run the program:

   ```bash
   ./main
   ```

Instructions for using the software:

1. Enter a name when prompted.
2. Enter the requested adjectives, nouns, verbs, foods, and other words.
3. Read the completed Halloween story at the end.
